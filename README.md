## 🚀 Featured Projects

### 🧠 [Turium AI: Knowledge Inbox (RAG Application)](https://github.com/Sahani199890/Knowledge-base-RAG-with-AI)
Full-stack, local-first Retrieval-Augmented Generation app. Ingest notes and web pages, then ask questions and get answers grounded only in your content, with source citations.
- **Ingestion pipeline:** HTML cleaning, configurable chunk size/overlap, 384-dim embeddings, and an async queue worker that serializes SQLite writes.
- **Hallucination guard:** a cosine-similarity relevance gate rejects out-of-domain queries instead of letting the LLM guess.
- **Citations:** every answer shows similarity scores and verbatim source chunks.
- **LLM flexibility:** Groq or OpenAI, with a local deterministic fallback so it runs with no API key.

**Stack:** Python, FastAPI, React, Vite, SQLite, Groq / OpenAI
